# Создание 3D-проекта танкового симулятора

Ниже описана базовая последовательность шагов, которая позволит развернуть 3D-проект в Unity и подключить предоставленные C#-скрипты для мехвода, наводчика и командира.

## 1. Создание нового проекта
1. Откройте Unity Hub и нажмите **New Project**.
2. Выберите шаблон **3D (URP не требуется)** и укажите место расположения проекта.
3. Нажмите **Create project**.

## 2. Подготовка сцены
1. Удалите объект `Main Camera`, если он есть в сцене.
2. Создайте пустой объект `TankRoot` и сбросьте позицию (0,0,0).
3. Импортируйте 3D-модель танка или соберите примитивами (корпус, башня, пушка).
4. Убедитесь, что:
   * `hull` — трансформ корпуса, который вращается при движении.
   * `turret` — трансформ башни, вращающийся по горизонтали.
   * `gunPivot` — отдельный пустой объект, являющийся дочерним `turret`, отвечает за наклон ствола.
   * `gunEnd` — точка вылета снаряда (дочерний объект `gunPivot`).
   * `recoilTransform` — объект ствола, который будет смещаться назад при выстреле.

## 3. Камеры экипажа
1. Добавьте три виртуальные камеры (Create > Camera) и разместите их:
   * **DriverCamera** — внутри корпуса, с ограниченным обзором вперёд.
   * **GunnerCamera** — рядом с прицелом пушки.
   * **CommanderCamera** — над башней, с обзором 360°.
2. У каждой камеры оставьте компонент `AudioListener`. Скрипт `TankController` сам будет включать/выключать нужный слушатель.

## 4. Управление и роли
1. Добавьте на сцену Canvas (Screen Space - Overlay) и UI-элементы: `roleText`, `ammoText`, `killsText`, `reloadSlider`, кнопки `driverBtn`, `gunnerBtn`, `commanderBtn`.
2. Создайте для командира дополнительный Canvas с RawImage/Panel для "монитора". Камеру командира можно продублировать в Render Texture и вывести на RawImage.
3. Подключите скрипт `TankController` к объекту `TankRoot` и укажите все публичные ссылки: Rigidbody, AudioSource, камеры, UI-элементы.
4. Назначьте кнопкам события `OnClick` → `TankRoot` → `TankController.SwitchCamera` через инспектор или воспользуйтесь методом `SetupButtons`, привязав соответствующие `Button`.

## 5. Движение и физика
1. Добавьте `Rigidbody` к `TankRoot`, включите `Use Gravity`, отключите `Angular Drag` (по вкусу).
2. Для корпуса используйте коллайдер (BoxCollider или MeshCollider).
3. При необходимости добавьте `WheelCollider` и собственную физику гусениц.

## 6. Оружие и снаряды
1. Создайте префаб снаряда, содержащий `Rigidbody` и скрипт `Shell`.
2. Укажите префаб в поле `shellPrefab` в `TankController`.
3. Для муляжа вспышки создайте Particle System, сохраните как префаб и подключите к `muzzleFlashPrefab`.

## 7. Противники и менеджер игры
1. Разместите объект `GameManager` и назначьте скрипт `GameManager.cs`.
2. Создайте префаб врага с `EnemyAI`, `Rigidbody`, коллайдером и скриптом смерти.
3. Задайте точки спауна (Transform[]) и подключите к `GameManager`.

## 8. Проверка
1. Запустите Play Mode.
2. Используйте клавиши `WASD` для движения мехвода.
3. Для переключения ролей нажимайте `1`, `2`, `3` или соответствующие кнопки UI.
4. Для наведения используйте мышь (горизонтальная ось — башня, вертикальная — угол пушки).
5. Стрельба доступна левой кнопкой мыши в роли наводчика или командира.

## 9. Дополнительные улучшения
* Добавьте анимацию гусениц, пост-эффекты камер, прицел с увеличением для наводчика.
* Реализуйте Damage UI на мониторе командира, вывод статуса модулей и экипажа.
* Подключите звуковой движок (FMOD/Wwise) для более реалистичных эффектов.

Следуя этим шагам, вы получите рабочую 3D-сцену танкового симулятора с тремя независимыми рабочими местами экипажа, готовую к дальнейшему наполнению контентом.
