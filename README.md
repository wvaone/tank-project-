# 🎮 TANK SIMULATOR PRO — ПОЛНОЕ РУКОВОДСТВО

> 🚛 Тактический симулятор танка с тремя ролями: механик-водитель, наводчик, командир.  
> 💥 Стрельба, перезарядка, враги с ИИ, звуки, визуальные эффекты, HUD, волны.  
> 🧩 Полностью настраиваемый и расширяемый проект для Unity.

---

Assets/

## 🎯 ОСОБЕННОСТИ

- ✅ **3 роли с переключением**:
  - **Механик-водитель** — управляет корпусом (WASD)
  - **Наводчик** — вращает башню и поднимает/опускает орудие (мышь)
  - **Командир** — свободный 360° обзор (мышь)

- ✅ **Реалистичная механика стрельбы**:  
  - Вспышка при выстреле  
  - Откат ствола  
  - Звук выстрела и перезарядки  
  - Ограниченный боезапас + автоматическая перезарядка патронов

- ✅ **Враги с ИИ**:  
  - Автоматически двигаются к игроку  
  - Имеют здоровье (несколько попаданий для уничтожения)  
  - Взрываются при смерти с эффектом и звуком

- ✅ **Система прогресса**:  
  - Счётчик убийств  
  - Волновая система (каждые 30 сек — новая волна, врагов всё больше)

- ✅ **Полный HUD**:  
  - Отображение текущей роли  
  - Боезапас (`AMMO: 5/10`)  
  - Слайдер перезарядки  
  - Количество убийств (`KILLS: 7`)  
  - Номер текущей волны (`WAVE 3`)

- ✅ **Звуковое сопровождение**:  
  - Двигатель (постоянный фон)  
  - Выстрел  
  - Перезарядка  
  - Взрыв

## 📥 УСТАНОВКА И НАСТРОЙКА

### 1. Создай новый 3D проект в Unity.

### 2. Скопируй структуру папок:

Скопируй папку `Assets` из этого архива в папку `Assets` своего Unity-проекта.

> 💡 Если Unity открыт — он автоматически импортирует скрипты.

> 🔧 **Нужен полный гайд с нуля?** Смотри [Docs/3DProjectSetup.md](Docs/3DProjectSetup.md) — там пошагово расписано, как развернуть 3D-проект, собрать сцену, подключить камеры и UI для всех трёх ролей экипажа.

### 3. Скачай звуковые эффекты:

Зайди на [freesound.org](https://freesound.org) и скачай:

| Файл                 | Поисковый запрос              | Пример ссылки (может меняться) |
|----------------------|-------------------------------|--------------------------------|
| `engine_loop.wav`    | “tank engine loop”            | https://freesound.org/s/220175 |
| `cannon_fire.wav`    | “cannon fire”                 | https://freesound.org/s/220174 |
| `explosion.wav`      | “explosion medium”            | https://freesound.org/s/411790 |
| `reload_click.wav`   | “gun reload mechanical”       | https://freesound.org/s/567380 |

📌 **Переименуй файлы точно так, как указано**, и помести их в `Assets/Audio/`.

### 4. Создай префабы вручную (если они не импортировались):

#### ➤ PlayerTank.prefab

1. GameObject → Create Empty → назови “PlayerTank”
2. Добавь дочерние объекты:
   - `Hull` (куб или модель корпуса)
   - `Turret` (вложенный в Hull, вращается наводчиком)
   - `GunPivot` (дочерний к Turret, ось подъёма пушки)
   - `GunEnd` (дочерний к GunPivot, точка выстрела)
   - `RecoilTransform` (дочерний к GunPivot — для анимации отката)
3. Добавь компоненты:
   - `Rigidbody` (на Hull, Freeze Rotation X и Z)
   - `Box Collider` или `Mesh Collider`
   - `TankController.cs`
4. В инспекторе `TankController` заполни все поля (камеры, звуки, UI и т.д.)
   - Укажи `Hull`, `Turret`, `GunPivot`, `GunEnd`, `RecoilTransform`
   - Привяжи камеры Driver/Gunner/Commander (оставь `AudioListener` только на активной камере во время игры — скрипт переключает сам)
   - Настрой кнопки ролей, тексты HUD, слайдер перезарядки
5. Перетащи объект в папку `Prefabs/` → готово!

#### ➤ Shell.prefab

1. GameObject → 3D Object → Sphere
2. Добавь `Rigidbody`, `Sphere Collider`
3. Добавь скрипт `Shell.cs`
4. Сделай префаб → сохрани в `Prefabs/Shell.prefab`

#### ➤ ExplosionEffect.prefab

1. GameObject → Effects → Particle System
2. Настрой:
   - Duration: 1
   - Start Lifetime: 0.5
   - Start Speed: 8
   - Gravity Modifier: 1
   - Shape: Sphere
   - Color over Lifetime: оранжевый → красный → прозрачный
3. Добавь `AutoDestroy.cs` (Lifetime = 2)
4. Добавь `AudioSource` → Play On Awake → назначь `explosion.wav`
5. Сделай префаб → `Prefabs/ExplosionEffect.prefab`

#### ➤ MuzzleFlash.prefab

1. GameObject → Effects → Particle System
2. Настрой короткую вспышку:
   - Duration: 0.3
   - Start Size: 0.5
   - Start Color: белый/жёлтый
   - Emission: 1 burst
3. Добавь `AutoDestroy.cs` (Lifetime = 0.5)
4. Сделай префаб → `Prefabs/MuzzleFlash.prefab`

#### ➤ EnemyTank.prefab

1. Создай аналогично PlayerTank, но:
   - Без камер
   - Добавь `EnemyAI.cs`
   - Назначь `explosionEffect` и `deathSound` в инспекторе
2. Сделай префаб → `Prefabs/EnemyTank.prefab`

#### ➤ HUDCanvas.prefab

1. GameObject → UI → Canvas
2. Добавь:
   - Panel (полупрозрачный фон)
   - Text: RoleText, AmmoText, KillsText, WaveText
   - Slider: ReloadSlider (стиль “Fill Area”)
   - 3 Button: Driver, Gunner, Commander (внизу экрана)
3. На Canvas добавь `GameManager.cs`
4. Привяжи кнопки и тексты в `TankController` и `GameManager`
5. Сделай префаб → `UI/HUDCanvas.prefab`

## 🛠️ ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

### ❓ Почему не стреляет?

- Проверь, что `currentAmmo > 0`
- Проверь, что `canFire = true` (не на перезарядке)
- Проверь, что назначены `shellPrefab` и `gunEnd` в `TankController`

### ❓ Почему враги не спавнятся?

- Проверь, что в `GameManager` назначены `spawnPoints` (пустые объекты на карте)
- Проверь, что назначен `enemyPrefab`

### ❓ Почему нет звука?

- Проверь, что аудиофайлы лежат в `Assets/Audio/` и назначены в инспекторе
- Проверь, что `AudioSource` на танке включён
- Проверь громкость в Unity и системе

### ❓ Как добавить больше ролей?

- Добавь новую камеру
- Расширь метод `SwitchCamera`
- Добавь новую кнопку в UI
- Реализуй логику управления для новой роли
